Política de privacidade

App “matadensa publisher” · atualizada em 23/09/2026

O que o app faz

O matadensa publisher é uma ferramenta de uso pessoal do dono do canal Mata Densa. Ele envia vídeos produzidos pelo próprio dono para o canal @matadensa no YouTube e para a conta @matadensa no TikTok e define título, descrição e data de publicação. Não é oferecido ao público.

Quais dados do Google ele acessa

  • youtube.upload: enviar vídeos para o canal autorizado.
  • youtube.readonly: ler a lista de vídeos do próprio canal, para não enviar o mesmo vídeo duas vezes.

O app não lê e-mail, contatos, arquivos nem qualquer outro dado da conta Google.

Quais dados do TikTok ele acessa

  • user.info.basic: nome e foto da conta, para confirmar que é a conta @matadensa.
  • video.upload e video.publish: enviar e publicar vídeos na conta autorizada.

O app não lê mensagens, seguidores, comentários nem vídeos de outras pessoas.

Onde os dados ficam

O token de acesso fica só no computador do dono do canal, fora de qualquer servidor. Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de IA.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O app usa os Serviços de API do YouTube; veja também a Política de Privacidade do Google.

Como revogar o acesso

Google: a qualquer momento em myaccount.google.com/permissions. TikTok: no app, em Configurações e privacidade → Segurança → Apps e serviços conectados. Ao revogar, o token deixa de funcionar e é apagado do computador.
