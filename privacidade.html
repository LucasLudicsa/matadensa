O que o app faz

O matadensa publisher é uma ferramenta de uso interno do estúdio Mata Densa. Ele envia vídeos produzidos pelo próprio estúdio para os nossos canais no YouTube e para as nossas contas no TikTok (@matadensa, @passadocensurado, @contraogolpe) e define título, descrição e data de publicação. Não é oferecido ao público.

Quais dados do Google ele acessa

  • youtube.upload: enviar vídeos para o canal autorizado.
  • youtube.readonly: ler o nome e a lista de vídeos do próprio canal, para confirmar que a conta autorizada é a certa e não enviar o mesmo vídeo duas vezes.

O app não lê e-mail, contatos, arquivos nem qualquer outro dado da conta Google.

Quais dados do TikTok ele acessa

  • user.info.basic: nome e foto da conta, para confirmar que é a conta certa.
  • video.upload e video.publish: enviar e publicar vídeos na conta autorizada.

O app não lê mensagens, seguidores, comentários nem vídeos de outras pessoas.

Uso dos Serviços de API do YouTube

Este app usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Os dados obtidos do YouTube também são tratados conforme a Política de Privacidade do Google.

Onde os dados ficam

O token de acesso fica só no computador do dono das contas, fora de qualquer servidor. Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de IA. O app não usa cookies nem coloca ou lê informações no navegador ou dispositivo de ninguém.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Este site

Este site é estático (GitHub Pages), não tem formulário, login, cookies nem ferramenta de análise. As miniaturas dos vídeos são carregadas do YouTube (i.ytimg.com); ao clicar num vídeo você vai para o YouTube, que segue a política do Google.

Como revogar o acesso e apagar os dados

Google: a qualquer momento na página de configurações de segurança do Google (security.google.com/settings/security/permissions). TikTok: no app, em Configurações e privacidade → Segurança → Apps e serviços conectados. Ao revogar, o token deixa de funcionar e é apagado do computador. O app não guarda dados da API do YouTube além do token; para pedir a exclusão de qualquer dado, escreva para o e-mail abaixo e ele é apagado em até 7 dias.

Privacy Policy (English)

Mata Densa website and the “matadensa publisher” app · last updated September 28, 2026

What the app does

matadensa publisher is an internal tool of the Mata Densa studio. It uploads videos produced by the studio to our own YouTube channels and TikTok accounts (@matadensa, @passadocensurado, @contraogolpe) and sets title, description and publish time. It is not offered to the public.

Google data accessed

youtube.upload to upload videos to the authorized channel; youtube.readonly to read the channel's own name and video list, to confirm the right account is connected and avoid uploading the same video twice. The app does not read email, contacts, files or any other Google account data.

TikTok data accessed

user.info.basic (display name and avatar, to confirm the connected account); video.upload and video.publish (upload and publish videos to the authorized account). The app does not read messages, followers, comments or other people's videos.

YouTube API Services

This app uses the YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and sharing

Access tokens are stored only on the account owner's computer, never on a server. No data is sold, shared with third parties, used for advertising or used to train AI models. The app does not use cookies or store or read information on anyone's browser or device. This website is static, with no forms, login, cookies or analytics; video thumbnails load from YouTube.

Revoking access and deleting data

Google: security.google.com/settings/security/permissions. TikTok: Settings and privacy → Security → Apps and services. Revoking invalidates the token and it is deleted from the computer. To request deletion of any data, email lucas.soldeira.ludicsa@gmail.com; it is deleted within 7 days.
